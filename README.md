# IsokoLink Rwanda

IsokoLink is a frontend-only React + Vite demo marketplace for farmers and buyers in Rwanda. Sign-in, profiles, produce listings, orders, cart contents, and community activity are handled with browser local storage. No backend server or database is required.

## Run locally

1. Install dependencies: `npm install`
2. Start the frontend: `npm run dev`

Use the demo accounts below, or register an account in the app:

- Farmer: `farmer.demo@isokolink.rw` / `FarmDemo2026!`
- Buyer: `buyer.demo@isokolink.rw` / `BuyerDemo2026!`

Demo data is saved in the current browser. Clearing browser storage resets local changes. Build the static frontend with `npm run build`.
